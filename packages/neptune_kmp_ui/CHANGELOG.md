# Changelog — neptune-odyssey-kmp

## 0.4.0 — Parity wave 3: templates, demo shell, icon set (unpublished)

- **Promoted out of `roadmap/` into `packages/`** after meeting the full
  4-point promotion bar (roadmap/ROADMAP.md) — first Central release now
  waits only on portal credentials.

- All 7 screen templates from neptune_templates.dart (auth, KYC, dashboard,
  cards, transfer, wallet, corporate) + the full 10-step onboarding flow
  (instruction, document/selfie capture, OCR review, form step, documents,
  terms, status/outcome, identity correction, OTP) in
  `ly.neptune.odyssey.ui.templates`.
- `NeptuneDemoShellApp` — the white-label demo shell: Welcome → 5-tab
  glass-dock shell (dashboard/transfer/cards/insights/profile), transfer
  outcome motion, EN/AR bilingual string table (41 keys, ported verbatim),
  live language/dark toggles, `logo` slot for client marks. Accepts a
  reference brand id, an `NO1-…` brandprint, or a `BrandprintConfig`.
- The full 94-icon set as `NptIcons` (generated by
  `tools/gen-icons.mjs` from packages/neptune_icons/src/icons.ts — CI
  drift-gated with `--check`), plus `nptIcon(name)` runtime lookup.
- Public `NeptuneStatCard` (web `npt-stat-card` / neptune_stat_card.dart —
  eyebrow label, tabular money value, optional unit/delta/chart slot); the
  dashboard template and demo shell now compose it instead of carrying
  private ports. 78 components total.
- Web font preloading: the resource accessors are public
  (`ly.neptune.odyssey.ui.resources.Res`, compose resources now an `api`
  dependency) so wasm/js consumers can `preloadFont` the bundled brand
  faces before the first frame — documented in README §Web; both gallery
  web entry points demonstrate the pattern.
- Maven Central release path, prepped but dormant (roadmap rule): per-module
  signing (in-memory PGP via `signingInMemoryKey*` properties, unsigned
  local publishing unaffected), a `centralBundle` task producing the Central
  Portal upload zip (14 publications, checksums, no repo metadata), and
  `.github/workflows/release-kmp.yml` (kmp-v* tag / manual dispatch, macOS
  runner, secret guards, USER_MANAGED upload).
- CI literal gate extended to `ui/templates/`; render sweep grew to
  30 sections × 4 brands × light/dark × LTR/RTL (480 frames), blank-gated.

## 0.1.0 — Foundation milestone (unpublished; roadmap)

- `:odyssey-tokens`: byte-identical Kotlin ports of the OKLCH↔sRGB converter,
  the v1 seed→palette ramp, the `NO1-` brandprint codec (append-only
  registries) and the logo seed extractor. Golden-tested on jvm, Android,
  iOS-native, js and wasm against `tokens.resolved.json` (every brand × mode ×
  role) and the 4 reference brandprints. Brand tables generated by
  `tools/codegen.mjs` (new `BrandData.g.kt` + `GoldenFixtures.g.kt` emitters,
  covered by the `codegen --check` drift gate).
- `:odyssey-compose-ui`: `NeptuneTheme` with the three entry points (brand id /
  brandprint / config) + 8 token groups as CompositionLocals (colors, shape,
  type, motion, identity, density, numerals, feedback); M3 `MaterialTheme`
  mapping; brand typography with Arabic type swap; `moneyStyle`/`formatDigits`;
  9 bundled OFL brand faces (static weights) + `NeptuneFontRegistry` for
  custom brands; reduced-motion detection per platform.
- Identity layer: `NeptuneGlass` (real backdrop blur, tint-only fallback),
  `NeptuneMotifLayer` (sonar/arcs/grid/guilloché painters), 135° RTL-aware
  hero gradient, `Modifier.nptShadow` painting the exact web elevation/glow
  recipes (dark mode = primary glow), `NeptuneEyebrow`.
- Core components (see COVERAGE.md for the honest ledger) + the multi-target
  gallery and the `renderShots` pixel sweep (SHOTS analog) gated by
  `tools/blank_check.py` in CI.
- Publish-ready Maven metadata for `ly.neptune.odyssey:odyssey-tokens` and
  `:odyssey-compose-ui` (verified via `publishToMavenLocal`; no Central
  credentials wired — deliberate, per the roadmap promotion bar).
