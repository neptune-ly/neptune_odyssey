# Changelog — neptune-odyssey-kmp

## 0.1.0 — Foundation milestone (unpublished; roadmap)

- `:odyssey-tokens`: byte-identical Kotlin ports of the OKLCH↔sRGB converter,
  the v1 seed→palette ramp, the `NO1-` brandprint codec (append-only
  registries) and the logo seed extractor. Golden-tested on jvm, Android,
  iOS-native, js and wasm against `tokens.resolved.json` (every brand × mode ×
  role) and the 4 reference brandprints. Brand tables generated by
  `tools/codegen.mjs` (new `BrandData.g.kt` + `GoldenFixtures.g.kt` emitters,
  covered by the `codegen --check` drift gate).
- `:odyssey-compose-ui`: `NeptuneTheme` with the three entry points (brand id /
  brandprint / config) + 8 token groups as CompositionLocals (colors, shape,
  type, motion, identity, density, numerals, feedback); M3 `MaterialTheme`
  mapping; brand typography with Arabic type swap; `moneyStyle`/`formatDigits`;
  9 bundled OFL brand faces (static weights) + `NeptuneFontRegistry` for
  custom brands; reduced-motion detection per platform.
- Identity layer: `NeptuneGlass` (real backdrop blur, tint-only fallback),
  `NeptuneMotifLayer` (sonar/arcs/grid/guilloché painters), 135° RTL-aware
  hero gradient, `Modifier.nptShadow` painting the exact web elevation/glow
  recipes (dark mode = primary glow), `NeptuneEyebrow`.
- Core components (see COVERAGE.md for the honest ledger) + the multi-target
  gallery and the `renderShots` pixel sweep (SHOTS analog) gated by
  `tools/blank_check.py` in CI.
- Publish-ready Maven metadata for `ly.neptune.odyssey:odyssey-tokens` and
  `:odyssey-compose-ui` (verified via `publishToMavenLocal`; no Central
  credentials wired — deliberate, per the roadmap promotion bar).
