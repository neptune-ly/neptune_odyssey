# Odyssey 3.0.0 — release verification

The new standard starts at 3.x; previous 2.x package versions belong to the first standard.

## Scope

Public shared kit and website; explicit Web/Flutter/KMP foundation profiles. Client-specific bank marks, artwork and journeys stay private. Earlier unreviewed widget-parity work is not included. Legacy themes and NO1 brandprints keep their defaults.

## Verified locally

- JavaScript packages: build and 183 tests pass. Configurator build passes.
- Flutter: analyzer clean; 387 tests pass, plus the optional eight-image foundation harness run separately.
- KMP JVM: 24 token tests and 11 UI/theme tests pass.
- Generated token and icon drift gates pass. Contrast covers legacy themes and all six 3.0 public profiles. Flutter/Web/KMP component literal gates pass.
- Browser: desktop and 390px mobile; composed and expressive states, Arabic and dark appearance, no horizontal overflow or missing images in inspected page state, no captured browser errors. Flutter EN/light and AR/dark foundation pixels inspected; currency labels use their language face separately from amounts.
- Public ZIP content and homepage local links checked; font licences and artwork provenance included. Figma start-page labels are 3.0; product version labels remain independent.

The release also repairs two existing gate problems: the KMP golden fixture count omitted the three light-mode card roles; several Flutter transparent masks/fills and capsule radii bypassed theme roles. Those changes preserve their rendering semantics. The release also refreshes generated KMP JS/Wasm lockfile versions and keeps accessibility test assertions compatible with CI’s pinned Flutter 3.35 SDK.

## Publication boundaries

GitHub source, Pages and the public design ZIP are the distribution channels for this release. npm/pub.dev jobs explicitly skip when their required credentials are absent; KMP Central remains a separate release workflow. No registry publication is claimed here. CI provides additional platform-build and legacy-gallery evidence on the release commit.

Figma native inventory is distinct from SDK implementation coverage. Artwork is internally reviewed; individual user production approval is not recorded. The prototype phase remains design-only, with the earlier live bank checks distinguished from Drive/Orbit native reaction-path checks in the private design audit.
