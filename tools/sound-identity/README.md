# Sound identity generator

The sound half of white-label, generalized: generate a distinct, 5-file
notification/success sound family for any bank/tenant with one command — the
same relationship `tools/client-demo` has to a *visual* brandprint, but for
sound. Built from the FluidSynth pipeline proven on two real bank apps
(Andalus, Nuran — see `~/GitHub/neptune/neptune-mobile/.agent/SOUND_IDENTITY_HANDOFF.md`
if you have that repo checked out; this tool generalizes it, not replaces it).

## Why this exists

Andalus and Nuran each got a hand-crafted sound identity in one-off sessions.
That doesn't scale to a third bank, a fourth, or a self-serve "pick your own
sound" flow for a customer — this tool turns that one-off work into a
repeatable, parameterized generator so a new identity is a CLI call, not
another bespoke session. "Each one can choose" (an explicit product
requirement): a bank can pick its own `--shape`/`--patch`, or let the tool
auto-assign one deterministically from its name.

## Why FluidSynth, not sine-wave synthesis

`packages/neptune_sound_kit` (the generic Flutter feedback-cue package) uses
plain sine-wave synthesis — zero dependencies, works everywhere, fine for a
generic "did something happen" chime. Real bank sound *identity* is a
different bar: FluidSynth + a sampled-instrument soundfont
(`VintageDreamsWaves-v2.sf2`, bundled with `brew install fluid-synth`)
produces categorically richer, more "designed" results — real vibraphone/
bell/harp timbres instead of a synthesized tone. This tool is a build-time
generator (like the client-demo CLI), producing static WAV files a mobile
app then bundles as native notification-channel resources — it does not run
inside a shipped app.

## Use it

```sh
node generate.mjs --name "First Gulf Libyan Bank"
```

Writes `output/<slug>/{success,general,money_in,security,reminder}.wav` —
5 files, 44.1kHz mono 16-bit PCM (the format both Android raw resources and
iOS bundled sounds require).

Override any auto-picked parameter:

```sh
node generate.mjs --name "First Gulf Libyan Bank" \
  --shape rising-phrase --patch 29 --base-note 79 --out /path/to/assets
```

- `--shape`: `rising-phrase` (two ascending notes — Andalus's family) or
  `tap-chord` (two taps into a landing chord — Nuran's family). Omit to
  auto-pick, preferring a shape not already in `registry.json`.
- `--patch` / `--layer-patch`: a soundfont program number (0–127). Omit to
  auto-pick from a curated pool of patches already confirmed to sound good
  on this soundfont (see `registry.json`'s `patches` map). Run
  `fluidsynth -ni -F /tmp/x.wav -f <(echo -e 'inst 1\nquit') <soundfont>`
  to list the full 136-patch catalog if you want to explore beyond the pool.
- `--base-note`: MIDI pitch of the phrase's root (default 79 = G5, matching
  both existing identities' register).

Every run appends to `registry.json`'s `identities` list so future runs (and
future operators) can see what's taken and avoid converging two banks onto
the same feel. Andalus and Nuran are recorded there as `external: true`
entries (they live in `neptune-mobile`, not generated by this tool) purely
for collision-avoidance bookkeeping.

## The derivation rule (same for every shape)

| Cue | Length | Feel |
|---|---|---|
| `success` | ~2.3s | the full hero phrase |
| `general` | ~1.65s | the hero phrase, trimmed |
| `money_in` | ~1.6s | brighter/warmer variant — wider or major interval, higher register |
| `security` | ~1.4s | wider interval + faster attack — more presence, still soft |
| `reminder` | ~1.0s | a single note only — calmest, quietest of the family |

## Preview before shipping

`preview/listening_room.html` is a self-contained page (inline base64 audio,
no external requests) so an operator can A/B candidates by ear before
committing. **Keep embedded payloads small** — encode at 64kbps mono for
preview purposes (`ffmpeg -i in.wav -b:a 64k -ac 1 out.mp3`); a page built
from high-bitrate encodes failed to load in an earlier round of this work.
The WAV files in `output/` are the real deliverable — the mp3s are
preview-only and never shipped to an app.

## Files

- `generate.mjs` — the CLI.
- `lib/midi.mjs` — a minimal hand-rolled Standard MIDI File encoder. Two
  bugs already found and fixed in the source pipeline are guarded here:
  a variable-length-quantity delta must reject negative input (a negative
  delta spins forever under JS's `>>` on negative numbers), and events must
  be sorted by absolute tick before delta-encoding (don't trust caller
  order — overlapping/legato notes are naturally out of order).
- `lib/shapes.mjs` — the melodic "shapes" (`rising-phrase`, `tap-chord`) and
  the per-cue duration/fade constants.
- `lib/pipeline.mjs` — MIDI → FluidSynth render → trim/fade → loudness-match
  (`loudnorm=I=-16:TP=-1.5:LRA=8`, so a family's four cues feel consistently
  loud) → finalize as mono 44.1kHz PCM WAV.
- `registry.json` — which (shape, patch) pairs are taken, and the curated
  patch pool with short character notes for each.

## Adding a shape

Two shapes today: a rising two-note phrase and a tap-tap-chord rhythm. A
genuinely new bank personality (not just a new instrument) is a new shape
function in `lib/shapes.mjs` returning the same cue map (`success`/`general`/
`money_in`/`security`/`reminder`, each a `{ ppq, tempoBpm, tracks }` object
`makeMidiFile` can consume) — register it in the `SHAPES` export and it's
immediately available via `--shape`.
