# Designer and agent contract

Read README.md → visual-compass.md → expression-system.md → illustration-guidelines.md before designing. Use the native identity board as the visual compass, then inspect actual component properties in Figma. Do not infer a final design from component counts or an old product screenshot.

## Fixed identity

Ink and warm paper anchor vivid cyan, coral, mint, lemon and lilac fields. Baloo 2 Bold is the expressive English display voice. Hanken Grotesk is composed display and functional English. Beiruti is Arabic. Numbers/identifiers use isolated Hanken LTR runs. Standard controls use 16px soft rectangles, pockets 24px, capsules 999px only when the pattern calls for a capsule.

## Source-backed institution overrides

Use the source application's original logo, colour, typography and verified flows. A bank can use a ledger register, balance-card stage or bare balance; do not force all three into an identical layout. Respect a faceless artwork requirement while retaining shared editorial craft. Change category, viewpoint and silhouette between adjacent scenes. Client-specific source assets belong in a separate private package.

## Deliberate freedom

Choose expressive or composed from the audience and task. Pick one dominant field; expressive may add two purposeful supporting groups, composed one precise accent. Vary scale, alignment and density rather than recolouring an identical card grid. Use rules/spacing for ordinary rows. Banks can be saturated and illustrated while keeping amounts, review details and outcomes clear.

Choose illustration category, viewpoint and silhouette before the subject. A dedicated image model or illustrator makes the artwork. Use the current studies for shared craft, not as a pose to repeat. Preserve prompts, source, crop and approval status; do not trace a raster and call it an editable master.

## Small working loop

1. State the product task, expression, dominant field, typography roles and illustration category.
2. Reuse native components/tokens. Add a new family only for a missing interaction contract.
3. Build the smallest representative fragment that proves the choice.
4. Render at real size. Check hierarchy, contrast, long text, Arabic, numeric isolation, light/dark, keyboard/focus and reduced motion where applicable.
5. Compare against the identity board. If the result looks generic without its logo, revise composition/colour/type before expanding screens.
6. Record what was actually verified. Internal inspection is not user approval.

Do not bring reference product names into Odyssey deliverables. Do not silently restore archived template or coverage backlogs. Runtime integrations and exhaustive SDK parity remain separate work.
